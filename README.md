## Цель работы
Разработать программную систему для предметной области «Ветеринарная клиника». Для каждой выделенной сущности (животное, ветеринар, обращение) необходимо определить набор характеристик, отражающих её основные свойства: для животного хранятся кличка, вид, порода, возраст и сведения о владельце; для врачей — их специализация; для обращения — врач, животное, дата приёма, диагноз и назначенное лечение. Также необходимо определить набор операций, описывающих допустимые действия над объектами, включая метод, контролирующий возможность записи животного к специалисту соответствующего профиля.

---

## Структура проекта
* `Animal` — класс, описывающий животное-пациента (характеристики и методы доступа к ним).
* `Vet` — класс, описывающий ветеринарного врача.
* `Appeals` — класс, описывающий конкретное обращение в клинику (агрегирует в себе объекты `Vet` и `Animal`).
* `VetClinic` — главный класс-менеджер. Содержит коллекции (`std::vector`) врачей, животных и обращений. Управляет их взаимодействием и проверяет логические ограничения.

---

## Файловая структура
* `main.cpp` — точка входа, содержит инициализацию тестовых данных и запуск главного меню.
* `animal.h` / `vet.h` / `appeals.h` / `vetClinic.h` — заголовочные файлы с объявлениями классов.
* `methods.cpp` — реализация всех методов (геттеры, сеттеры, конструкторы, логика) для классов.
* `functions.h` / `functions.cpp` — вспомогательные функции (очистка буфера, пользовательское интерактивное меню).
---

## 🚀 Основной функционал (Меню)

1. **Добавление ветеринара** (ФИО и специализация: Терапевт, Орнитолог, Ратолог и т.д.).
2. **Добавление животного** (Кличка, вид, порода, возраст и данные владельца).
3. **Запись на прием** (Фиксация даты, диагноза и назначенного лечения).
4. **Просмотр базы врачей**.
5. **Просмотр базы животных**.
6. **Просмотр истории обращений**.
