# Ветеринарная клиника

Консольное C++-приложение для управления работой ветеринарной клиники. Программа позволяет вести список животных и ветеринаров, оформлять обращения и просматривать историю приёмов. При создании обращения проверяется, подходит ли специализация выбранного врача для указанного вида животного.

## Возможности приложения

- добавление животных и ветеринаров;
- просмотр списка зарегистрированных животных;
- просмотр списка ветеринарных врачей и их специализаций;
- запись животного на приём с указанием даты, диагноза и назначенного лечения;
- просмотр истории обращений;
- удаление животных и ветеринаров;
- проверка наличия животного и врача при оформлении обращения;
- проверка соответствия специализации врача виду животного.

При запуске программа заполняет клинику несколькими демонстрационными животными, ветеринарами и обращениями. Данные хранятся в памяти во время работы приложения; сохранение в файл не реализовано.

## Предметная область

В приложении используются три основных типа данных:

- **Животное (`Animal`)** — кличка, вид, порода, возраст и имя владельца.
- **Ветеринар (`Vet`)** — имя врача и его специализация.
- **Обращение (`Appeals`)** — ветеринар, животное, дата приёма, диагноз и назначенное лечение.

Класс `VetClinic` управляет коллекциями животных, ветеринаров и обращений. Перед оформлением обращения приложение проверяет, существуют ли указанные животное и врач, а также соответствует ли специализация врача виду животного.

1. Скачайте или клонируйте репозиторий.
2. Откройте исходные файлы в Visual Studio. Если готового решения Visual Studio в репозитории нет, создайте проект типа **Console App** и добавьте в него файлы из каталогов `header files` и `source files`.
3. Установите стандарт языка **ISO C++20** или новее в настройках проекта.
4. Соберите и запустите программу.

После запуска появится консольное меню:

| Пункт | Действие |
|---:|---|
| `1` | Добавить ветеринара |
| `2` | Добавить животное |

| `4` | Показать список ветеринаров |
| `5` | Показать список животных |
| `6` | Показать историю обращений |
| `7` | Удалить ветеринара |
| `8` | Удалить животное |
| `0` | Выйти из приложения |

## Лабораторная работа №2: дружественные функции и перегрузка операторов

**Тема:** Дружественные функции, перегрузка функций и операторов.  
**Вариант:** 8 — «Ветеринарная клиника».

### Цель работы

Расширить программную систему, разработанную в предыдущей лабораторной работе, используя дружественные функции и перегрузку операторов. Необходимо реализовать осмысленное сравнение объектов, ввод и вывод данных, операции добавления и удаления связанных объектов, а также обработку ситуаций, когда выполнение операции невозможно.

### Реализация требований лабораторной

#### Класс `Animal`

- `operator==` — считает животных равными, если совпадают их кличка и владелец;
- `operator<=>` — сравнивает животных по возрасту;
- `operator<<` — выводит информацию о животном;
- `operator>>` — считывает данные животного.

Операторы `<<` и `>>` объявлены дружественными функциями, поэтому могут обращаться к закрытым полям класса.

#### Класс `Vet`

- `operator==` — сравнивает ветеринаров по имени;
- `operator<<` и `operator>>` — выводят и считывают данные ветеринара.

#### Класс `Appeals`

Хранит сведения об обращении: врача, животное, дату приёма, диагноз и назначенное лечение. Оператор `<<` используется для вывода информации об обращении.

#### Класс `VetClinic`

- `operator+=` — добавляет животное или ветеринара в клинику;
- `operator-=` — удаляет животное или ветеринара из клиники.

Для операций предусмотрены проверки, связанные с поиском животных и ветеринаров и проверкой специализации при оформлении приёма.

### Результат лабораторной работы

В результате создано консольное приложение «Ветеринарная клиника», в котором перегрузка операторов и дружественные функции применяются для решения задач выбранной предметной области, а не только для формального выполнения требований задания.
