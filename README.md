# Ветеринарная клиника

Консольное приложение на C++ для управления ветеринарной клиникой. Оно позволяет регистрировать животных и ветеринаров, оформлять обращения, просматривать историю приёмов и проверять, подходит ли специализация врача для выбранного животного.

Приложение демонстрирует объектно-ориентированное программирование на C++: наследование, полиморфизм, абстрактные классы, перегрузку операторов, шаблоны и обработку исключений.

## Возможности

- добавление ветеринаров с указанием имени и специализации;
- добавление собак, кошек, птиц и грызунов с индивидуальными характеристиками;
- просмотр списка ветеринаров и зарегистрированных животных;
- автоматическая сортировка животных по возрасту при добавлении;
- оформление обращения с указанием врача, животного, даты, диагноза и лечения;
- проверка наличия врача и животного, а также совместимости специализации врача с видом животного;
- просмотр истории обращений;
- удаление ветеринаров и животных;
- проверка введённых данных и обработка ошибок.

При запуске клиника заполняется начальными данными: тремя ветеринарами, четырьмя животными и тремя обращениями. После этого открывается основное меню. Все данные хранятся в оперативной памяти и удаляются после завершения программы — сохранение в файл или базу данных не реализовано.

## Предметная область

| Сущность | Назначение |
|---|---|
| `Animal` | Абстрактный базовый класс животного. Содержит кличку, породу, возраст и имя владельца. |
| `Dog`, `Cat`, `Bird`, `Rodent` | Производные классы с характеристиками и поведением, специфичными для вида животного. |
| `Vet` | Ветеринар: имя и специализация. |
| `Appeals` | Обращение: ветеринар, животное, дата, диагноз и назначенное лечение. |
| `VetClinic` | Управляет коллекциями животных, ветеринаров и обращений. |
| `Collection<T>` | Универсальный шаблонный контейнер, используемый для хранения данных клиники. |

### Иерархия животных

```text
Animal (абстрактный базовый класс)
├── Dog     — количество прогулок в день
├── Cat     — количество волосяных комков в месяц
├── Bird    — размах крыльев
└── Rodent   — длина резцов
```

Каждый производный класс реализует собственные методы получения типа, звука и стоимости осмотра, а также ввода и вывода характеристик.

## Запуск приложения

### Требования

- операционная система Windows;
- Visual Studio 2022 с компонентом разработки классических приложений на C++;
- поддержка стандарта **C++20**, включая `<format>` и `<ranges>`.

Программа использует заголовок `<Windows.h>` для настройки кодовой страницы консоли, поэтому текущая версия рассчитана на Windows.

### Сборка в Visual Studio

В архиве находятся исходные файлы, но нет готового файла решения Visual Studio (`.sln`) или проекта (`.vcxproj`). Для сборки:

1. Распакуйте архив, не меняя расположение каталогов `headers`, `sources` и `exception`.
2. Создайте в Visual Studio проект **Console App (C++)**.
3. Добавьте в проект все `.cpp`-файлы из каталога `sources`.
4. Убедитесь, что каталоги `headers` и `exception` находятся на прежних местах относительно `sources`: исходные файлы подключают заголовки через относительные пути.
5. В свойствах проекта выберите стандарт языка **ISO C++20** (`/std:c++20`).
6. Соберите и запустите проект.

### Главное меню

| Пункт | Действие |
|---:|---|
| `1` | Add a veterinarian — добавить ветеринара |
| `2` | Add an animal — добавить животное |
| `3` | Schedule an appointment — оформить обращение |
| `4` | Show all doctors — показать ветеринаров |
| `5` | Show all animals — показать животных |
| `6` | Show appointment history — показать историю обращений |
| `7` | Remove veterinarian — удалить ветеринара |
| `8` | Remove the animal — удалить животное |
| `0` | Exit — выйти из программы |

Ввод выполняется построчно. При добавлении животного сначала нужно выбрать его тип. Затем программа показывает подсказку с перечнем общих и дополнительных полей. При оформлении обращения врач выбирается по специализации, а животное — по кличке. Если найдено несколько врачей одной специализации, используется первый из них в коллекции.

Для удаления ветеринара вводится его полное имя. Для удаления животного нужно указать кличку и имя владельца.

## Реализованные темы лабораторных работ

### Лабораторная работа №2. Дружественные функции и перегрузка операторов

**Вариант:** 8 — «Ветеринарная клиника».

В проекте реализованы перегрузки операторов для сравнения, ввода и вывода объектов, а также для добавления и удаления элементов клиники.

**Класс `Animal`:**

- `operator==` сравнивает животных по кличке и имени владельца;
- `operator<=>` сравнивает животных по возрасту. На его основе доступны операторы сравнения, а клиника сортирует животных при добавлении;
- `operator<<` и `operator>>` вызывают виртуальные методы `print()` и `read()`, поэтому корректно работают с объектами производных классов;
- отдельная перегрузка `operator<<` позволяет выводить `std::shared_ptr<Animal>` как данные животного, а не как адрес.

**Класс `Vet`:**

- `operator==` сравнивает ветеринаров по имени;
- `operator<<` и `operator>>` обеспечивают вывод и ввод имени и специализации.

**Класс `Appeals`:** дружественный `operator<<` выводит информацию о ветеринаре, животном, дате, диагнозе и лечении.

**Класс `VetClinic`:**

- `operator+=` добавляет животное или ветеринара;
- `operator-=` удаляет животное или ветеринара;
- `removeAnimal(name, owner)` позволяет удалить животное по кличке и владельцу без создания объекта абстрактного класса `Animal`.

Если объект для удаления не найден, генерируется `NotFoundException`. При добавлении проверяется наличие дубликатов.

### Лабораторная работа №3. Наследование

`Animal` выступает базовым классом, от которого наследуются `Dog`, `Cat`, `Bird` и `Rodent`. Общие характеристики (кличка, порода, возраст и владелец) хранятся в базовом классе, а дополнительные параметры — в производных.

| Класс | Дополнительное поле | Специфический метод |
|---|---|---|
| `Dog` | `walksPerDay` — прогулок в день | `weeklyWalkHours()` — расчёт часов прогулок в неделю |
| `Cat` | `hairballsPerMonth` — волосяных комков в месяц | `groomingsPerWeek()` — расчёт рекомендуемой частоты вычёсывания |
| `Bird` | `wingspan` — размах крыльев | `minCageWidth()` — расчёт минимальной ширины клетки |
| `Rodent` | `incisorLength` — длина резцов | `daysUntilDentalTrim()` — оценка количества дней до подрезания резцов |

Метод `canBeTreatedBy()` определяет, может ли врач выбранной специализации лечить животное. В базовом классе запрещены специализации `Ornithologist` и `Rodentologist`; `Bird` и `Rodent` переопределяют это правило:

| Тип животного | Специализации, которым запрещён приём |
|---|---|
| `Dog`, `Cat` | `Ornithologist`, `Rodentologist` |
| `Bird` | `Therapist`, `Rodentologist` |
| `Rodent` | `Therapist`, `Ornithologist` |

### Лабораторная работа №4. Полиморфизм и абстрактные классы

`Animal` является абстрактным классом: у него есть три чисто виртуальных метода, которые должны быть реализованы в каждом производном классе:

- `getType()` — возвращает тип животного;
- `checkupPrice()` — рассчитывает стоимость осмотра;
- `makeSound()` — возвращает характерный звук.

Также в базовом классе определены виртуальные методы `careAdvice()`, `canBeTreatedBy()`, `print()`, `read()` и `inputHint()`. Производные классы переопределяют их, когда требуется поведение, зависящее от вида животного.

Полиморфизм используется, например, при хранении разных видов животных в одной коллекции `Collection<std::shared_ptr<Animal>>`: вызов виртуального метода через указатель на базовый класс приводит к выполнению реализации фактического типа объекта.

Стоимость осмотра рассчитывается по разным формулам в классах-наследниках. Это демонстрационная логика проекта, а не реальные ветеринарные тарифы.

| Класс | Расчёт стоимости осмотра |
|---|---|
| `Dog` | `67 + weeklyWalkHours() * 2 + (возраст > 8 ? 15 : 0)` |
| `Cat` | `67 + groomingsPerWeek() * 4` |
| `Bird` | `67 + wingspan * 0.5 + (wingspan > 50 ? 25 : 0)` |
| `Rodent` | `67 + (daysUntilDentalTrim() == 0 ? 20 : 0)` |

Для совместного владения животными используются `std::shared_ptr`. Один объект может одновременно храниться в клинике и в обращении. Поэтому удаление животного из списка клиники не уничтожает объект, пока на него ссылается запись в истории обращений.

### Лабораторная работа №5. Шаблоны и обобщённое программирование

#### Шаблонный класс `Collection<T>`

Класс находится в `headers/collection.h` и использует `std::vector<T>` для хранения элементов. Он не зависит от предметной области и предоставляет следующие операции:

| Метод или оператор | Назначение |
|---|---|
| `add(item)` | добавить элемент в конец коллекции |
| `removeIf(condition)` | удалить первый элемент, удовлетворяющий условию |
| `findIf(condition)` | найти первый подходящий элемент или вернуть `nullptr` |
| `operator[](index)` | получить элемент по индексу с проверкой границ |
| `size()` | получить количество элементов |
| `empty()` | проверить, пуста ли коллекция |
| `clear()` | удалить все элементы |
| `begin()` / `end()` | обеспечить перебор коллекции в цикле range-based `for` |
| `print(os)` | вывести элементы через `operator<<` |

Условия поиска и удаления передаются в виде предикатов, в том числе лямбда-выражений. При обращении по недопустимому индексу `operator[]` выбрасывает `OutOfRangeException`.

В `VetClinic` шаблон используется для трёх типов данных:

- `Collection<std::shared_ptr<Animal>>` — животные;
- `Collection<Vet>` — ветеринары;
- `Collection<Appeals>` — обращения.

#### Шаблонная функция `findAll`

Функция из `headers/findAll.h` перебирает `Collection<T>` и возвращает `std::vector<T>` со всеми элементами, удовлетворяющими переданному условию. В отличие от `findIf`, который возвращает первый найденный элемент, `findAll` собирает все совпадения. Это вспомогательная функция; текущий сценарий основного меню её не вызывает.

### Обработка исключений

Для разделения разных ситуаций в проекте созданы собственные классы исключений в каталоге `exception/`:

| Исключение | Для чего используется |
|---|---|
| `InputFormatException` | введено значение неподходящего формата, например текст вместо числа |
| `InvalidDataException` | данные не прошли проверку: пустое обязательное поле или значение вне допустимых ограничений |
| `DuplicateException` | попытка добавить уже зарегистрированное животное или ветеринара |
| `NotFoundException` | ветеринар или животное не найдены при поиске или удалении |
| `IncompatibleVetException` | специализация ветеринара не подходит для выбранного животного |
| `OutOfRangeException` | обращение к элементу `Collection<T>` по недопустимому индексу |

Ошибки, возникающие при работе с меню, перехватываются с помощью `try`/`catch` и выводятся в консоль. Это позволяет сообщить пользователю о проблеме и продолжить работу программы в предусмотренных сценариях.
