## Цель работы

Расширить программную систему «Ветеринарная клиника», разработанную в предыдущей лабораторной работе, с использованием дружественных функций и перегрузки операторов.

В программе необходимо обеспечить сравнение объектов, ввод и вывод данных, управление связанными объектами, а также проверку корректности выполнения операций.

---

## Описание предметной области

В ветеринарной клинике принимаются животные различных видов. Для каждого животного хранятся:

- кличка;
- вид;
- порода;
- возраст;
- сведения о владельце.

В клинике работают ветеринары различных специализаций. Для каждого обращения хранятся:

- ветеринарный врач;
- животное;
- дата приёма;
- диагноз;
- назначенное лечение.

При записи животного на приём выполняется проверка соответствия специализации ветеринара виду животного.

## Реализованные классы

### `Animal`

Класс описывает животное-пациента и содержит его основные характеристики.

Реализованы:

- оператор `==` — сравнение животных по кличке и владельцу;
- оператор `<=>` — сравнение животных по возрасту;
- оператор `<<` — вывод информации об объекте;
- оператор `>>` — ввод данных объекта.

Операторы `<<` и `>>` реализованы как дружественные функции и имеют доступ к закрытым данным класса.

### `Vet`

Класс описывает ветеринарного врача.

Реализован:

- оператор `==` — сравнение ветеринаров по имени.

Также перегружены операторы `<<` и `>>` для вывода и ввода данных объекта.

### `Appeals`

Класс описывает обращение животного в клинику и связывает между собой ветеринара, животное, дату приёма, диагноз и лечение.

Для вывода информации об обращении используется перегруженный оператор `<<`.

### `VetClinic`

Основной управляющий класс программы. Содержит коллекции животных, ветеринаров и обращений.

Реализованы:

- `operator+=` для добавления животного или ветеринара;
- `operator-=` для удаления животного или ветеринара;
- проверка возможности записи животного к ветеринару соответствующей специализации;
- обработка ситуаций отсутствия необходимого объекта.

## Основной функционал

Программа предоставляет консольное меню:

1. Добавление ветеринара.
2. Добавление животного.
3. Запись животного на приём.
4. Просмотр списка ветеринаров.
5. Просмотр списка животных.
6. Просмотр истории обращений.
7. Удаление ветеринара.
8. Удаление животного.
0. Выход из программы.

При работе программы демонстрируются перегруженные операторы ввода, вывода, сравнения, добавления и удаления объектов.

## Используемые технологии

- **Язык программирования:** C++
- **Стандарт:** C++20
- **Контейнер:** `std::vector`

## Запуск

Открыть проект в **Visual Studio**, выполнить сборку проекта и запустить программу.

После запуска открывается консольное меню, через которое можно добавлять, удалять и просматривать животных и ветеринаров, а также создавать обращения.

В `main.cpp` также присутствуют заранее подготовленные объекты для демонстрации работы программы.

---

## Обработка ошибок

Программа проверяет корректность выполнения основных операций. При записи на приём выполняется проверка существования животного и ветеринара, а также соответствия специализации ветеринара виду животного.

При попытке удалить отсутствующий объект операция не выполняется.
